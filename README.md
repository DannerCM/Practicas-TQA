# Practicas-TQA

Prácticas y ejercicios desarrollados durante las clases de la materia Testing y
Quality Assurance.

Cada práctica se guarda en su propia carpeta, con el enunciado y la resolución
correspondiente: pruebas de caja blanca, escenarios en Gherkin, tablas de decisión,
partición de equivalencia y los demás ejercicios trabajados en clase.

Materia: Testing, Quality Assurance
Carrera de Ingeniería en Sistemas, Universidad Privada Franz Tamayo

## Prácticas de automatización de pruebas

- [Práctica 1](02-practica1-selenium-ide/): Selenium IDE, grabación y ejecución con side-runner.
- [Práctica 2](03-practica2-webdriver/): Selenium WebDriver con Python.
- [Práctica 3](04-practica3-robot/): Robot Framework con SeleniumLibrary.

### Requisitos

- Python 3.10 o superior
- Google Chrome
- Node.js (solo para side-runner de la práctica 1)
